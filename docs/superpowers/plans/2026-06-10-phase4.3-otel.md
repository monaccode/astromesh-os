# Fase 4.3 — OTel exportando (spans a un collector) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Activate the runtime's dormant OpenTelemetry OTLP trace export and bake an OTel Collector sidecar into the OS image, so an observability-enabled node exports its agent-run spans to a node-local collector, proven by a 1-VM gate.

**Architecture:** Vertical across two repos. In `../astromesh` (node source) we turn on the existing OTLP bridge (`TelemetryManager` + `OTLPCollector`) config-driven and off-by-default, and wire the engine to emit each completed trace. We rebuild the `.deb`. In `astromesh-os` (this repo) we bake `otelcol` (core) as a guarded systemd unit listening on `localhost:4317` with a `debug` exporter, extend the 4.1 machine-config to flip `observability.otlp.enabled`, and add a gate that POSTs to the baked `phase0-smoke` agent (stub mode) and asserts the collector logged the span.

**Tech Stack:** OpenTelemetry SDK/OTLP-gRPC (already a `astromesh-node` dep), OpenTelemetry Collector (core `otelcol`), nfpm (`.deb` build), systemd, QEMU/swtpm, the 4.1 SMBIOS machine-config, the phase0 stub-OpenAI server, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-06-10-phase4.3-otel-design.md`

## Discovery facts (verified during planning)

- **OTLP bridge dormant:** `astromesh/observability/telemetry.py` (`TelemetryManager`/`TelemetryConfig`, default `otlp_endpoint="http://localhost:4317"`) and `collector.py` (`OTLPCollector(InternalCollector)`, "Bridges TracingContext spans to OpenTelemetry") exist; `opentelemetry-{api,sdk,exporter-otlp}>=1.27` are `astromesh-node` deps (in the `.deb` venv). But `TelemetryManager(` is built only in tests, `.setup()` is never called, and `traces.py:6` uses `_collector = InternalCollector()`.
- **`emit_trace` has no caller:** `engine.run()` builds `tracing` (a `TracingContext`) and at the end does `tracing.finish_span(root_span); result["trace"] = tracing.to_dict(); return result` (engine.py ~612-620), and on exception `finish_span(root_span, ERROR); raise` (~622-626). Nothing calls `get_collector().emit_trace(tracing)`. **Activation must wire the emit** (in a `finally`, so failed LLM calls still export the pre-LLM spans).
- **Collector global:** `astromesh/api/routes/traces.py` has `_collector`, `set_collector()`, `get_collector()` (lines 6/9-11/14-15). Replacing `_collector` with `OTLPCollector(tm)` makes both `/v1/traces` AND OTLP work (OTLPCollector extends InternalCollector).
- **Config:** `astromesh-node/.../daemon/config.py` `DaemonConfig.from_dict()` reads `spec.{api,services,peers,mesh}`. No `observability` block today. Daemon startup: `run_daemon()` (core.py ~71-131) builds `AgentRuntime`, calls `await runtime.bootstrap()`, then sets runtimes on routes, then `uvicorn` serves.
- **Agent run API:** `POST /v1/agents/{agent_name}/run`, body `{"query": str, "session_id": str="default", "context": dict|null}` (agents.py ~163; `AgentRunRequest` ~37). Response includes `trace`.
- **Stub mode (OS):** `PHASE0_MODE=stub` (default) installs `phase0/agents/phase0-smoke.stub.yaml` as `/etc/astromesh/agents/phase0-smoke.agent.yaml` (agent `metadata.name: phase0-smoke`, provider `openai_compat` at `http://127.0.0.1:8081/v1`) and runs `phase0-stub.service` (`tests/stub-openai/stub_server.py`). So `POST /v1/agents/phase0-smoke/run` succeeds and emits the full span tree over loopback (egress-filter-safe).
- **`.deb` build:** `astromesh-node/packaging/build-deb.sh` → venv (`pip install ../ ".[systemd]"`) → `nfpm package --config packaging/nfpm.yaml`. Version `0.1.1`. `nfpm` is NOT installed in WSL (Go absent) → download the nfpm binary. The OS `dist/*.deb` is **gitignored** (fetched from CI). Local: rebuild + copy to `astromesh-os/dist/`.
- **Egress (3.5):** astromeshd's `IPAddressDeny=any` allows `localhost` → OTLP to `localhost:4317` and stub `127.0.0.1:8081` both pass. No egress change needed.

- [ ] **Step 3: Implement** — add a classmethod to `TelemetryConfig` in `telemetry.py`. The precedence is: explicit dict `endpoint` > `OTEL_EXPORTER_OTLP_ENDPOINT` env > default. `enabled` defaults False (export off unless asked).

```python
import os
from dataclasses import dataclass


@dataclass
class TelemetryConfig:
    service_name: str = "astromesh"
    otlp_endpoint: str = "http://localhost:4317"
    enabled: bool = True
    sample_rate: float = 1.0

    @classmethod
    def from_env_and_dict(cls, observability: dict) -> "TelemetryConfig":
        """Build from a runtime.yaml spec.observability dict + OTEL_* env, export off by default."""
        otlp = (observability or {}).get("otlp", {}) or {}
        endpoint = (
            otlp.get("endpoint")
            or os.environ.get("OTEL_EXPORTER_OTLP_ENDPOINT")
            or "http://localhost:4317"
        )
        return cls(
            otlp_endpoint=endpoint,
            enabled=bool(otlp.get("enabled", False)),
        )
```

(Leave the existing class body — `setup()`, `get_tracer()`, etc. — unchanged; only add the `import os` and the classmethod, and the `enabled` default stays `True` for the direct constructor used by existing tests.)

- [ ] **Step 1: Write the render script** — `phase4/otel/otel-collector-render.sh`:

```bash
#!/usr/bin/env bash
# Fase 4.3: render the otelcol config to writable /run (the baked config is on read-only verity) and
# exec the collector. Guarded: no-op unless the active runtime.yaml enabled OTLP export.
set -uo pipefail
log() { echo "[otel] $*"; }
RT=/var/lib/astromesh/runtime.yaml
grep -qE '^[[:space:]]*enabled:[[:space:]]*true' "${RT}" 2>/dev/null && grep -q 'otlp:' "${RT}" 2>/dev/null \
    || { log "not an otel boot; skipping collector"; exit 0; }
SRC_CFG=/usr/lib/astromesh-os/otel/otelcol.yaml
RUN_CFG=/run/otel/otelcol.yaml
install -d -m 0755 /run/otel
install -m 0644 "${SRC_CFG}" "${RUN_CFG}"
modprobe nf_conntrack 2>/dev/null || true   # harmless; otelcol needs no kmods, kept for parity
log "OTEL-COLLECTOR OK (config=${RUN_CFG} listen=127.0.0.1:4317)"
exec /usr/bin/otelcol --config "${RUN_CFG}"
```

**Files:**

- [ ] **Step 1: Write the gate** — `tests/boot/otel-export-and-assert.sh` (reuse `lib-smbios.sh` + `lib-swtpm.sh`; 1 VM, hostfwd :8000):

```bash
#!/usr/bin/env bash
# Fase 4.3 gate: boot ONE VM with an `otel` machine-config (flips observability.otlp.enabled). Assert
# the baked otelcol sidecar is up and that a real agent run's spans are EXPORTED to it (the collector's
# debug exporter logs received spans to console). Positive: agent.run span reaches the collector.
set -euo pipefail
IMAGE="${1:?usage: otel-export-and-assert.sh <v1-raw-image>}"
HERE="$(cd "$(dirname "$0")" && pwd)"
source "${HERE}/lib-smbios.sh"
source "${HERE}/lib-swtpm.sh"

PORT=8000
if [ -w /dev/kvm ]; then ACCEL="-enable-kvm"; SMP=2; else ACCEL="-accel tcg,thread=multi"; SMP=4; fi
OVMF_CODE=""; for c in /usr/share/OVMF/OVMF_CODE_4M.fd /usr/share/OVMF/OVMF_CODE.fd; do [ -f "$c" ] && { OVMF_CODE="$c"; break; }; done
OVMF_VARS_SRC=""; for v in /usr/share/OVMF/OVMF_VARS_4M.fd /usr/share/OVMF/OVMF_VARS.fd; do [ -f "$v" ] && { OVMF_VARS_SRC="$v"; break; }; done
[ -n "${OVMF_CODE}" ] && [ -n "${OVMF_VARS_SRC}" ] || { echo "[otel] FAIL: OVMF not found"; exit 1; }

TPM="$(mktemp -d)/t"; QPID=""
cleanup() { kill ${QPID} 2>/dev/null || true; SWTPM_DIR="${TPM}" swtpm_stop 2>/dev/null || true; }
trap cleanup EXIT

disk="otel.qcow2"; vars="ovmf_vars_otel.fd"; CON="otel-console.log"
qemu-img convert -O qcow2 "${IMAGE}" "${disk}"; qemu-img resize "${disk}" +3G >/dev/null
cp "${OVMF_VARS_SRC}" "${vars}"
swtpm_start "${TPM}"
CRED_YAML="profile: worker
node_id: otel-node
otel: true"
qemu-system-x86_64 ${ACCEL} -machine q35 -m 2048 -smp ${SMP} -nographic \
    -global ICH9-LPC.disable_s3=1 \
    -drive if=pflash,format=raw,unit=0,readonly=on,file="${OVMF_CODE}" \
    -drive if=pflash,format=raw,unit=1,file="${vars}" \
    -drive file="${disk}",format=qcow2,if=virtio \
    $(swtpm_qemu_args) \
    -smbios "$(smbios_machine_config "${CRED_YAML}")" \
    -nic user,model=virtio-net-pci,hostfwd=tcp::${PORT}-:8000 \
    > "${CON}" 2>&1 &
QPID=$!

echo "[otel] waiting for /v1/health (timeout 420s)"
deadline=$(( $(date +%s) + 420 ))
until curl -fsS "http://localhost:${PORT}/v1/health" >/dev/null 2>&1; do
    [ "$(date +%s)" -ge "${deadline}" ] && { echo "[otel] FAIL: health never came up"; tail -n 120 "${CON}"; exit 1; }
    sleep 3
done

grep -aq "otel\] OTEL-COLLECTOR OK" "${CON}" || { echo "[otel] FAIL: collector not up"; grep -aE 'otel\]' "${CON}" | tail; exit 1; }
echo "[otel] OTEL-COLLECTOR OK (sidecar listening)"

echo "[otel] triggering an agent run (stub provider) to emit spans"
curl -fsS -X POST "http://localhost:${PORT}/v1/agents/phase0-smoke/run" \
    -H 'Content-Type: application/json' \
    -d '{"query":"otel gate ping","session_id":"otel-gate"}' >/dev/null 2>&1 || true

echo "[otel] asserting agent.run span reached the collector (debug exporter on console)"
deadline=$(( $(date +%s) + 60 ))
until grep -aqE 'agent\.run' "${CON}" && grep -aqE 'service\.name.*astromesh|astromesh' "${CON}"; do
    [ "$(date +%s)" -ge "${deadline}" ] && { echo "[otel] FAIL: no exported agent.run span in collector output"; grep -aE 'otel\]|Span|agent\.run|ScopeSpans' "${CON}" | tail -n 40; exit 1; }
    sleep 3
done
echo "[otel] SPAN-EXPORTED OK (agent.run reached the collector over OTLP)"
echo "[otel] OTEL EXPORT GATE PASSED"
```
