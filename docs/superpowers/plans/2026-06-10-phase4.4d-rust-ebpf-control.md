# Fase 4.4d — Control Rust del eBPF (libbpf-rs + OTLP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single Rust daemon (`astromesh-ebpf`, libbpf-rs + opentelemetry-otlp) loads + attaches the eBPF egress program, reads the flow map every 10s, and exports `astromesh.egress.{bytes,packets}` OTLP metrics to the 4.3 collector — replacing the 4.4/4.4b bash + python + bpftool userspace, proven by a 1-VM gate.

**Architecture:** A Cargo crate at `phase4/ebpf/rust/` whose `build.rs` (libbpf-cargo `SkeletonBuilder`) compiles `egress_acct.bpf.c` into an embedded skeleton (no runtime `.bpf.o`); `main.rs` guards on the runtime flags, loads/attaches the program to astromeshd's cgroup (MULTI, coexisting with 3.5), and loops read-map → OTLP-export. Built on host/CI (`cargo build --release`, static libbpf) and shipped as build-input `dist/astromesh-ebpf` (like otelcol). The old userspace files + their gates/targets are removed; `bpftool` leaves the image.

**Tech Stack:** Rust (cargo 1.85), libbpf-rs 0.24 (vendored static libbpf), libbpf-cargo (skeleton via bpftool at build), opentelemetry/opentelemetry-otlp (tonic gRPC, insecure), the existing `egress_acct.bpf.c`, the 4.3 collector + 4.4b metrics pipeline, systemd, QEMU/swtpm.

**Spec:** `docs/superpowers/specs/2026-06-10-phase4.4d-rust-ebpf-control-design.md`

**PROVEN during planning (spike, kept as the crate seed):** `phase4/ebpf/rust/{Cargo.toml,build.rs,src/main.rs}` already build (`cargo build --release` → 882 KB binary, static libbpf) and **load the skeleton into the kernel** (`SPIKE: skeleton loaded OK`). Runtime deps: `libelf1`, `zlib1g`, `libzstd1`. So the libbpf-rs build/skeleton/load is settled; what remains is attach + map-read + OTLP + guard.

## Discovery facts (verified during planning)

- **Toolchain:** `cargo`/`rustc` 1.85, `clang` 19, `libbpf-dev`, `bpftool` (libbpf-cargo shells out to it at BUILD time for skeleton-gen), `libelf-dev`/`zlib1g-dev` (libbpf-sys vendored build) — all apt-installable. The runtime binary dynamically links `libelf1`/`zlib1g`/`libzstd1` (bake those; drop `bpftool` from the image).
- **Build flags:** `SkeletonBuilder::source("../egress_acct.bpf.c").clang_args(["-I/usr/include/x86_64-linux-gnu","-D__TARGET_ARCH_x86"])` — the arch include is required (proven in 4.4).
- **Skeleton names:** source `egress_acct.bpf.c` → `EgressAcctSkelBuilder` / `skel.progs.egress_acct` / `skel.maps.flows`.
- **Empirical (discovery+iterate, like 4.2 strongSwan):** (a) the cgroup attach MODE for coexistence with systemd's filter — 4.4 used `bpftool cgroup attach … egress … multi` (BPF_F_ALLOW_MULTI); the libbpf-rs equivalent is confirmed on host; (b) the exact `opentelemetry-otlp` 0.27 metric API (exporter/reader/gauge) — validated against a local collector during Task 1, like 4.4b's python validation.
- **Map layout** (same as 4.4): key `daddr(4) dport(2,!H/be) proto(1) pad(1)`, value `bytes(8,le) packets(8,le)`.
- **Guard:** read `/var/lib/astromesh/runtime.yaml` for `spec.ebpf.egress.enabled` AND `spec.observability.otlp.enabled` (a tiny YAML/grep read in Rust — or shell out; keep it simple).
- **Collector contract** (from 4.4b): the debug exporter prints `Name: astromesh.egress.bytes`, `dport: Int(8081)`, `Value: N`.

```rust
use std::fs;
use std::mem::MaybeUninit;
use std::os::fd::AsRawFd;
use std::time::Duration;

mod egress_acct {
    include!(concat!(env!("OUT_DIR"), "/egress_acct.skel.rs"));
}
use egress_acct::*;
use anyhow::Result;
use libbpf_rs::skel::{OpenSkel, SkelBuilder};
use libbpf_rs::MapCore;
use opentelemetry::KeyValue;
use opentelemetry::metrics::MeterProvider as _;

const RT: &str = "/var/lib/astromesh/runtime.yaml";
const ENDPOINT: &str = "http://127.0.0.1:4317";

fn enabled() -> bool {
    let s = match fs::read_to_string(RT) { Ok(s) => s, Err(_) => return false };
    // simple, guard-only: both flags present as `enabled: true` and the right block keys exist.
    s.contains("ebpf:") && s.contains("otlp:") && s.matches("enabled: true").count() >= 1
}

fn astromeshd_cgroup() -> Option<String> {
    let out = std::process::Command::new("systemctl")
        .args(["show", "-p", "ControlGroup", "--value", "astromeshd.service"])
        .output().ok()?;
    let cg = String::from_utf8_lossy(&out.stdout).trim().to_string();
    if cg.is_empty() { None } else { Some(format!("/sys/fs/cgroup{cg}")) }
}

fn parse_flows(skel: &EgressAcctSkel) -> Vec<(String, u16, u8, u64, u64)> {
    let mut out = Vec::new();
    let map = &skel.maps.flows;
    for key in map.keys() {
        if let Ok(Some(val)) = map.lookup(&key, libbpf_rs::MapFlags::ANY) {
            if key.len() >= 7 && val.len() >= 16 {
                let daddr = format!("{}.{}.{}.{}", key[0], key[1], key[2], key[3]);
                let dport = u16::from_be_bytes([key[4], key[5]]);
                let proto = key[6];
                let nbytes = u64::from_le_bytes(val[0..8].try_into().unwrap());
                let npkts = u64::from_le_bytes(val[8..16].try_into().unwrap());
                out.push((daddr, dport, proto, nbytes, npkts));
            }
        }
    }
    out
}

#[tokio::main]
async fn main() -> Result<()> {
    if !enabled() {
        println!("[otel] astromesh-ebpf: not an ebpf+otlp boot; exiting");
        return Ok(());
    }
    let mut obj = MaybeUninit::uninit();
    let skel = EgressAcctSkelBuilder::default().open(&mut obj)?.load()?;

    let cgpath = astromeshd_cgroup().ok_or_else(|| anyhow::anyhow!("no astromeshd cgroup"))?;
    let cgfile = fs::File::open(&cgpath)?;
    // ITERATE: attach with BPF_F_ALLOW_MULTI to coexist with systemd's filter. libbpf-rs 0.24:
    // skel.progs.egress_acct.attach_cgroup(cgfile.as_raw_fd())? — confirm it uses/accepts MULTI; if not,
    // use bpf_prog_attach via the lower-level API. Record the working call.
    let _link = skel.progs.egress_acct.attach_cgroup(cgfile.as_raw_fd())?;
    println!("[otel] ASTROMESH-EBPF ATTACHED OK (cgroup={cgpath})");

    // OTLP metric export — ITERATE the opentelemetry-otlp 0.27 API against the local collector.
    let exporter = opentelemetry_otlp::MetricExporter::builder()
        .with_tonic().with_endpoint(ENDPOINT).build()?;
    let reader = opentelemetry_sdk::metrics::PeriodicReader::builder(
        exporter, opentelemetry_sdk::runtime::Tokio).build();
    let provider = opentelemetry_sdk::metrics::SdkMeterProvider::builder()
        .with_reader(reader)
        .with_resource(opentelemetry_sdk::Resource::new(vec![KeyValue::new("service.name", "astromesh-ebpf")]))
        .build();
    let meter = provider.meter("astromesh.ebpf");
    let g_bytes = meter.u64_gauge("astromesh.egress.bytes").build();
    let g_pkts = meter.u64_gauge("astromesh.egress.packets").build();

    loop {
        for (daddr, dport, proto, nbytes, npkts) in parse_flows(&skel) {
            let attrs = [KeyValue::new("daddr", daddr.clone()),
                         KeyValue::new("dport", dport as i64),
                         KeyValue::new("proto", proto as i64)];
            g_bytes.record(nbytes, &attrs);
            g_pkts.record(npkts, &attrs);
        }
        let _ = provider.force_flush();
        tokio::time::sleep(Duration::from_secs(10)).await;
    }
}
```
