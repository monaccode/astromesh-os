# Fase 4.2 — Mesh over IPsec (cluster CA, TPM-sealed node key) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two nodes (mesh-gateway + mesh-worker, selected by 4.1 machine-config) form the runtime's gossip mesh, but all node-to-node traffic is carried inside an IPsec (IKEv2) tunnel whose mutual auth uses X.509 certs from a self-owned cluster CA, with each node's private key sealed to the TPM — so a node without a CA-signed cert can't establish the SA and can't reach any peer (R2 closure).

**Architecture:** A baked cluster CA cert (trust anchor). On first boot a oneshot issues the node a cert (`CN=node_id`, `SAN=mesh_ip`) signed by the baked CA key and seals the private key to the TPM (reusing the 3.3 tpm2-tools PCR 11+12 pattern); each boot un-seals it to tmpfs. strongSwan (`swanctl`) loads an IKEv2 connection (`local.auth=pubkey` with the node cert, `remote.auth=pubkey` + `remote.cacerts=ca.crt`) and an ESP child SA protecting the mesh subnet. The runtime is unchanged (`mesh.bind=<mesh_ip>:8000`, plain HTTP) and rides inside the SA. All of this is gated on a `mesh-*` profile, so non-mesh boots (Fase 0/2/3/4.1 gates) are untouched. The gate boots 2 VMs joined by a QEMU `socket` netdev and asserts `cluster_size==2` over an established SA, plus a no-cert client is rejected.

**Tech Stack:** strongSwan 6 (`swanctl`/`charon`), Linux XFRM/ESP (cloud kernel modules: `esp4`, `xfrm_user`, …), tpm2-tools (PCR 11+12 seal, reused from 3.3), openssl (cluster CA), systemd credentials (machine-config from 4.1), QEMU `socket` netdev, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-06-09-phase4.2-mesh-mtls-design.md`

**Patterns to mirror:** `phase3/tpm/astromesh-{seal,unseal}-secret.sh` (TPM seal/unseal, PCR 11+12, owner-hierarchy ecc primary, `/var` flush+sync), `phase4/machineconfig/astromesh-machine-config.sh` (machine-config oneshot to extend), `phase3/secureboot/{db.key,db.crt,README.md}` (committed TEST keypair + caveat), `tests/boot/lib-swtpm.sh` + `tests/boot/tpm-seal-and-assert.sh` (swtpm harness + multi-VM-ish gate), `mkosi.conf` `Packages=`, the Fase 3.x postinst blocks.

**Branch:** `feat/phase4.2-mesh` (created; spec committed there).

## Discovery facts (verified during planning)

- **`advertise == bind`:** the mesh manager advertises `url=f"http://{self._config.bind}"` (`manager.py:37`) and POSTs to peers at `target.url + /v1/mesh/{join,gossip,heartbeat}`. So `mesh.bind` MUST be the node's routable mesh IP. App-layer mTLS sidecars are out → IPsec at L3.
- **`/v1/mesh/state`** returns `cluster_state().to_dict()`; `ClusterState.nodes` is a dict keyed by node_id. **cluster_size = `len(state["nodes"])`**.
- **Kernel IPsec:** the image's `6.12.90+deb13.1-cloud-amd64` ships `kernel/net/ipv4/esp4.ko.xz`, `xfrm_user`, `xfrm_algo`, `af_key`, `ah4` (verified by mounting the built root). `modprobe esp4` works; no rebuild of the kernel needed.
- **strongSwan** is trixie `6.0.1-6+deb13u6` → add to `Packages=`; config via `swanctl`/`/etc/swanctl/`.
- **TPM seal pattern (3.3):** tpm2-tools, owner-hierarchy `ecc` primary (`tpm2_createprimary -C o -g sha256 -G ecc`), PCR 11+12 policy (`tpm2_policypcr -l sha256:11,12`), sealed data object `-a fixedtpm|fixedparent|adminwithpolicy`, blobs in `/var/lib/astromesh/secrets/`, `sync` after write. Reuse verbatim, sealing the node's EC private key.
- **/etc is read-only verity:** the mesh seed/bind must NOT rely on writing `/etc/hosts`; instead the machine-config oneshot rewrites the rendered `runtime.yaml`'s `mesh.bind`/`mesh.seeds` to concrete IPs (the rendered `runtime.yaml` lives in writable `/var` per 4.1).
- **Mesh profiles** (`mesh-gateway.yaml`, `mesh-worker.yaml`) carry `spec.mesh.{enabled,node_name,bind,seeds,...}`; `mesh-worker` seeds `[http://gateway:8000]`.

### Task 2: Per-node cert issuance + TPM seal (first boot)

**Files:** Create `phase4/mesh/mesh-cert-issue.sh`, `phase4/mesh/mesh-cert-issue.service`

- [ ] **Step 1: Write the issue+seal script** `phase4/mesh/mesh-cert-issue.sh`:

```bash
#!/usr/bin/env bash
# Fase 4.2: first boot — issue this node a cert (CN=node_id, SAN=mesh_ip) signed by the baked cluster
# CA, and SEAL the private key to the TPM (PCR 11+12, same tpm2-tools pattern as Fase 3.3). Idempotent.
# Guarded: no-op unless the active runtime.yaml is a mesh profile. The CA key is baked (TEST); prod
# issues out-of-band. node_id/mesh_ip come from the machine-config (exported by the 4.1 oneshot to
# /run/astromesh/mesh/env).
set -uo pipefail
log() { echo "[mesh] $*"; }

RT=/var/lib/astromesh/runtime.yaml
grep -qE '^[[:space:]]*enabled:[[:space:]]*true' "${RT}" 2>/dev/null && grep -q 'mesh:' "${RT}" 2>/dev/null || { log "not a mesh profile; skipping cert issue"; exit 0; }

# shellcheck disable=SC1091
[ -f /run/astromesh/mesh/env ] && . /run/astromesh/mesh/env   # MESH_NODE_ID, MESH_IP, MESH_PEER_IP
NODE_ID="${MESH_NODE_ID:-}"; MESH_IP="${MESH_IP:-}"
[ -n "${NODE_ID}" ] && [ -n "${MESH_IP}" ] || { log "FAIL: missing MESH_NODE_ID/MESH_IP from machine-config"; exit 1; }

CA_CRT=/usr/lib/astromesh-os/mesh/ca.crt
CA_KEY=/usr/lib/astromesh-os/mesh/ca.key
SECRETS=/var/lib/astromesh/secrets
CERT=/var/lib/astromesh/mesh/node.crt        # public, not secret
SEALPUB="${SECRETS}/mesh.seal.pub"
SEALPRIV="${SECRETS}/mesh.seal.priv"
POLICY="${SECRETS}/mesh.policy"
WORK="$(mktemp -d /run/mesh-cert.XXXXXX)"; trap 'rm -rf "${WORK}"' EXIT

if [ -f "${SEALPRIV}" ] && [ -f "${CERT}" ]; then log "already issued+sealed; CERT-SEALED OK"; exit 0; fi

install -d -m 0700 "${SECRETS}"; install -d -m 0755 /var/lib/astromesh/mesh

# 1. Keypair + CSR + cert signed by the cluster CA (CN=node_id, SAN=IP:mesh_ip).
openssl ecparam -genkey -name prime256v1 -out "${WORK}/node.key" 2>/dev/null || { log "FAIL: genkey"; exit 1; }
openssl req -new -key "${WORK}/node.key" -subj "/CN=${NODE_ID}/" -out "${WORK}/node.csr" 2>/dev/null || { log "FAIL: csr"; exit 1; }
openssl x509 -req -in "${WORK}/node.csr" -CA "${CA_CRT}" -CAkey "${CA_KEY}" -CAcreateserial \
    -days 3650 -sha256 -extfile <(printf 'subjectAltName=IP:%s\nextendedKeyUsage=serverAuth,clientAuth\n' "${MESH_IP}") \
    -out "${CERT}" 2>/dev/null || { log "FAIL: sign cert"; exit 1; }

# 2. Seal the private key to the TPM (PCR 11+12), reusing the Fase 3.3 mechanism.
TPM2TOOLS_TCTI=""
for d in /dev/tpmrm0 /dev/tpm0; do if [ -e "$d" ]; then export TPM2TOOLS_TCTI="device:$d"; break; fi; done
[ -n "${TPM2TOOLS_TCTI}" ] || { log "FAIL: no TPM device"; exit 1; }
tpm2_flushcontext -t 2>/dev/null || true; tpm2_flushcontext -s 2>/dev/null || true
tpm2_startauthsession -S "${WORK}/trial.ctx" >/dev/null 2>&1 || { log "FAIL: startauthsession"; exit 1; }
tpm2_policypcr -S "${WORK}/trial.ctx" -l sha256:11,12 -L "${WORK}/policy.digest" >/dev/null 2>&1 \
    || { tpm2_flushcontext "${WORK}/trial.ctx" 2>/dev/null || true; log "FAIL: policypcr"; exit 1; }
tpm2_flushcontext "${WORK}/trial.ctx" 2>/dev/null || true
tpm2_createprimary -C o -g sha256 -G ecc -c "${WORK}/primary.ctx" >/dev/null 2>&1 || { log "FAIL: createprimary"; exit 1; }
tpm2_create -C "${WORK}/primary.ctx" -i "${WORK}/node.key" \
    -u "${WORK}/seal.pub" -r "${WORK}/seal.priv" -L "${WORK}/policy.digest" \
    -a "fixedtpm|fixedparent|adminwithpolicy" >/dev/null 2>&1 || { log "FAIL: tpm2_create (seal)"; exit 1; }
install -m 0600 "${WORK}/seal.pub" "${SEALPUB}"; install -m 0600 "${WORK}/seal.priv" "${SEALPRIV}"; install -m 0600 "${WORK}/policy.digest" "${POLICY}"
sync
log "CERT-SEALED OK (CN=${NODE_ID} SAN=${MESH_IP})"
```

### Task 3: Per-boot node-key unseal

**Files:** Create `phase4/mesh/mesh-cert-unseal.sh`, `phase4/mesh/mesh-cert-unseal.service`

- [ ] **Step 1:** `phase4/mesh/mesh-cert-unseal.sh` (mirror `phase3/tpm/astromesh-unseal-secret.sh`, target `/run/astromesh/mesh/node.key`):

```bash
#!/usr/bin/env bash
# Fase 4.2: each boot — unseal the node's mesh private key to tmpfs (/run/astromesh/mesh/node.key),
# 0600, readable by strongSwan. Same PCR 11+12 policy-session pattern as Fase 3.3 unseal. Guarded.
set -uo pipefail
log() { echo "[mesh] $*"; }
RT=/var/lib/astromesh/runtime.yaml
grep -qE '^[[:space:]]*enabled:[[:space:]]*true' "${RT}" 2>/dev/null && grep -q 'mesh:' "${RT}" 2>/dev/null || { log "not a mesh profile; skipping unseal"; exit 0; }

SECRETS=/var/lib/astromesh/secrets
SEALPUB="${SECRETS}/mesh.seal.pub"; SEALPRIV="${SECRETS}/mesh.seal.priv"
OUT=/run/astromesh/mesh/node.key
WORK="$(mktemp -d /run/mesh-unseal.XXXXXX)"; trap 'rm -rf "${WORK}"' EXIT
install -d -m 0700 /run/astromesh/mesh; rm -f "${OUT}"
[ -f "${SEALPRIV}" ] && [ -f "${SEALPUB}" ] || { log "no sealed mesh key; degraded"; exit 0; }
TPM2TOOLS_TCTI=""
for d in /dev/tpmrm0 /dev/tpm0; do if [ -e "$d" ]; then export TPM2TOOLS_TCTI="device:$d"; break; fi; done
[ -n "${TPM2TOOLS_TCTI}" ] || { log "FAIL: no TPM device"; exit 1; }
tpm2_flushcontext -t 2>/dev/null || true; tpm2_flushcontext -s 2>/dev/null || true
tpm2_createprimary -C o -g sha256 -G ecc -c "${WORK}/primary.ctx" >/dev/null 2>&1 || { log "FAIL: createprimary"; exit 1; }
tpm2_load -C "${WORK}/primary.ctx" -u "${SEALPUB}" -r "${SEALPRIV}" -c "${WORK}/seal.ctx" >/dev/null 2>&1 || { log "FAIL: tpm2_load"; exit 1; }
tpm2_startauthsession --policy-session -S "${WORK}/us.ctx" >/dev/null 2>&1 || { log "FAIL: startauthsession"; exit 1; }
tpm2_policypcr -S "${WORK}/us.ctx" -l sha256:11,12 >/dev/null 2>&1 || { tpm2_flushcontext "${WORK}/us.ctx" 2>/dev/null || true; log "FAIL: policypcr"; exit 1; }
if tpm2_unseal -p "session:${WORK}/us.ctx" -c "${WORK}/seal.ctx" > "${OUT}" 2>"${WORK}/e"; then
    chmod 0600 "${OUT}"; log "KEY-UNSEALED OK"
else
    rm -f "${OUT}"; log "FAIL: unseal (PCR 11/12 mismatch?): $(tr -d '\n' < "${WORK}/e")"; exit 1
fi
tpm2_flushcontext "${WORK}/us.ctx" 2>/dev/null || true
```

```bash
#!/usr/bin/env bash
# Fase 4.2: assign the static mesh IP to the QEMU socket-netdev NIC (the second interface). Guarded.
set -uo pipefail
log() { echo "[mesh] $*"; }
RT=/var/lib/astromesh/runtime.yaml
grep -qE '^[[:space:]]*enabled:[[:space:]]*true' "${RT}" 2>/dev/null && grep -q 'mesh:' "${RT}" 2>/dev/null || { log "not a mesh profile; skipping net"; exit 0; }
[ -f /run/astromesh/mesh/env ] && . /run/astromesh/mesh/env
[ -n "${MESH_IP:-}" ] || { log "FAIL: no MESH_IP"; exit 1; }
# The mesh NIC is the interface WITHOUT the DHCP default route (slirp NIC has it). Pick the second
# ethernet link by name order; the plan's discovery confirms the exact match (e.g. enp0s2 vs enp0s1).
mesh_if=$(ls /sys/class/net | grep -E '^(en|eth)' | sort | sed -n 2p)
[ -n "${mesh_if}" ] || { log "FAIL: no second NIC for mesh"; exit 1; }
mkdir -p /run/systemd/network
cat > /run/systemd/network/30-mesh.network <<NET
[Match]
Name=${mesh_if}
[Network]
Address=${MESH_IP}/24
NET
networkctl reload 2>/dev/null || true
log "MESH-NET OK (${mesh_if} ${MESH_IP}/24)"
```

- [ ] **Step 1: Draft the render script** `phase4/mesh/swanctl-render.sh`:

```bash
#!/usr/bin/env bash
# Fase 4.2: render /etc/swanctl/{conf.d/mesh.conf,x509ca,x509,private} from the issued cert + unsealed
# key + machine-config, modprobe esp4, and bring up the IKEv2 SA to the peer. Guarded.
set -uo pipefail
log() { echo "[mesh] $*"; }
RT=/var/lib/astromesh/runtime.yaml
grep -qE '^[[:space:]]*enabled:[[:space:]]*true' "${RT}" 2>/dev/null && grep -q 'mesh:' "${RT}" 2>/dev/null || { log "not a mesh profile; skipping ipsec"; exit 0; }
[ -f /run/astromesh/mesh/env ] && . /run/astromesh/mesh/env
NODE_ID="${MESH_NODE_ID:?}"; MESH_IP="${MESH_IP:?}"; PEER_IP="${MESH_PEER_IP:?}"
CA=/usr/lib/astromesh-os/mesh/ca.crt
CERT=/var/lib/astromesh/mesh/node.crt
KEY=/run/astromesh/mesh/node.key   # unsealed (Task 3)
[ -f "${CERT}" ] && [ -f "${KEY}" ] || { log "FAIL: missing cert/key"; exit 1; }
modprobe esp4 2>/dev/null || true

# swanctl wants creds under /etc/swanctl, which is read-only verity. Point charon at a writable dir
# instead via SWANCTL_DIR (/run), populated here.
SW=/run/swanctl
install -d -m 0755 "${SW}"/{conf.d,x509ca,x509,private}
install -m 0644 "${CA}"   "${SW}/x509ca/ca.crt"
install -m 0644 "${CERT}" "${SW}/x509/node.crt"
install -m 0600 "${KEY}"  "${SW}/private/node.key"
cat > "${SW}/conf.d/mesh.conf" <<CONF
connections {
  mesh {
    version = 2
    local_addrs  = ${MESH_IP}
    remote_addrs = ${PEER_IP}
    local  { auth = pubkey ; certs = node.crt ; id = ${NODE_ID} }
    remote { auth = pubkey ; cacerts = ca.crt }
    children {
      mesh {
        local_ts  = ${MESH_IP}/32
        remote_ts = ${PEER_IP}/32
        mode = transport
        start_action = trap
      }
    }
    mobike = no
  }
}
CONF
# strongSwan 6: run charon (systemd unit strongswan.service) then load creds + conns.
systemctl start strongswan.service 2>/dev/null || systemctl start strongswan-starter.service 2>/dev/null || true
SWANCTL_DIR="${SW}" swanctl --load-all 2>&1 | sed 's/^/[mesh:swanctl] /' || { log "FAIL: swanctl --load-all"; exit 1; }
SWANCTL_DIR="${SW}" swanctl --initiate --child mesh 2>/dev/null || true   # trap also brings it up on first packet
```
