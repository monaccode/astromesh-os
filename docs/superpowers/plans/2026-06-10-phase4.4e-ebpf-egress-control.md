# Fase 4.4e — Control real: enforcement de egress por quota Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The eBPF program gains a `deny` map (drops egress to denied flows); the Rust daemon (4.4d) writes a flow to `deny` once its bytes exceed a configured quota — so an agent that overruns its egress budget to a destination gets cut off at the kernel, proven by a 1-VM gate.

**Architecture:** Extend `egress_acct.bpf.c` with a `deny` BPF hash map keyed by the same `flow_key`; at the top of the handler, `bpf_map_lookup_elem(&deny, &key)` → `return 0` (DROP) before counting. Extend the 4.4d Rust daemon to read `spec.ebpf.egress.quota_bytes` from runtime.yaml and, in its read loop, write any over-quota flow's key to `deny` (+ log the decision). The machine-config sets the quota (low in the gate). OS-only (no node/.deb change).

**Tech Stack:** eBPF (`cgroup_skb/egress` + a deny map), libbpf-rs 0.24 (the 4.4d daemon), the 4.4d build-input/service/dev-loop, the 4.1 machine-config, QEMU/swtpm, the phase0 stub.

**Spec:** `docs/superpowers/specs/2026-06-10-phase4.4e-ebpf-egress-control-design.md`

**Single repo:** `astromesh-os` (no node-source change).

## Discovery facts (verified during planning)

- **4.4d daemon** (`phase4/ebpf/rust/src/main.rs`): `#[tokio::main]`, builds the skel, `attach_cgroup`, then a `loop` that calls `parse_flows(&skel)` (iterates `skel.maps.flows` via `map.keys()` + `map.lookup`) and records OTLP gauges, then `sleep(10s)`. The skeleton exposes `skel.maps.flows` and `skel.progs.egress_acct`.
- **eBPF** (`phase4/ebpf/egress_acct.bpf.c`): `cgroup_skb/egress`, `struct flow_key {__u32 daddr; __u16 dport; __u8 proto; __u8 pad;}`, `flows` hash map, returns 1. Currently builds `key.dport` inside the TCP/UDP branch — must build the FULL key before the deny check.
- **libbpf-rs map write:** `skel.maps.deny.update(&key_bytes, &[1u8], libbpf_rs::MapFlags::ANY)?`. Key bytes = the raw 8-byte key from `flows.keys()` (same layout) — reuse it directly (no reconstruction).
- **Quota:** read from `/var/lib/astromesh/runtime.yaml` `quota_bytes: <n>`; default high (no deny without config). The gate's machine-config sets it to 500.
- **Enforcement demo:** `cgroup_skb/egress` returning 0 drops the skb (incl. loopback) for astromeshd's cgroup → astromeshd can't send to `127.0.0.1:8081` → the agent's provider call fails. The exact failure shape in the `/v1/agents/.../run` response is an empirical gate item.
- **Patterns to mirror:** 4.4d (`ebpf-rust-and-assert.sh`, `ensure_ebpf_rust`, the machine-config `ebpf_egress` block, `phase4-ebpf-rust.yml`).

### Task 1: eBPF deny map + drop

**Files:** Modify `phase4/ebpf/egress_acct.bpf.c`

- [ ] **Step 1:** Add the `deny` map after the `flows` map definition:

```c
struct {
    __uint(type, BPF_MAP_TYPE_HASH);
    __uint(max_entries, 4096);
    __type(key, struct flow_key);
    __type(value, __u8);
} deny SEC(".maps");
```

- [ ] **Step 2:** Restructure the handler so the FULL key (incl. dport) is built, then deny-checked, then counted. Replace the body from `struct flow_key key = {};` to the end with:

```c
    struct flow_key key = {};
    key.daddr = iph->daddr;
    key.proto = iph->protocol;

    __u32 ihl = iph->ihl * 4;
    void *l4 = (void *)iph + ihl;
    if (iph->protocol == IPPROTO_TCP) {
        struct tcphdr *th = l4;
        if ((void *)(th + 1) > data_end)
            return 1;
        key.dport = th->dest;
    } else if (iph->protocol == IPPROTO_UDP) {
        struct udphdr *uh = l4;
        if ((void *)(uh + 1) > data_end)
            return 1;
        key.dport = uh->dest;
    }

    /* Fase 4.4e: enforcement — drop egress to denied flows (before counting). */
    if (bpf_map_lookup_elem(&deny, &key))
        return 0;

    struct flow_stat *st = bpf_map_lookup_elem(&flows, &key);
    if (st) {
        __sync_fetch_and_add(&st->bytes, skb->len);
        __sync_fetch_and_add(&st->packets, 1);
    } else {
        struct flow_stat init = { .bytes = skb->len, .packets = 1 };
        bpf_map_update_elem(&flows, &key, &init, BPF_NOEXIST);
    }
    return 1;
```

### Task 2: Rust daemon — quota → deny

**Files:** Modify `phase4/ebpf/rust/src/main.rs`

- [ ] **Step 1:** Add a quota reader near `enabled()`:

```rust
fn quota_bytes() -> u64 {
    let s = match std::fs::read_to_string(RT) {
        Ok(s) => s,
        Err(_) => return u64::MAX,
    };
    for line in s.lines() {
        let l = line.trim();
        if let Some(rest) = l.strip_prefix("quota_bytes:") {
            if let Ok(n) = rest.trim().parse::<u64>() {
                return n;
            }
        }
    }
    u64::MAX // no quota configured -> deny nothing
}
```

- [ ] **Step 2:** Change `parse_flows` to also return the raw key bytes (so the daemon can write the exact key to `deny`):

```rust
fn parse_flows(skel: &EgressAcctSkel) -> Vec<(Vec<u8>, String, u16, u8, u64, u64)> {
    let mut out = Vec::new();
    let map = &skel.maps.flows;
    for key in map.keys() {
        if let Ok(Some(val)) = map.lookup(&key, libbpf_rs::MapFlags::ANY) {
            if key.len() >= 7 && val.len() >= 16 {
                let daddr = format!("{}.{}.{}.{}", key[0], key[1], key[2], key[3]);
                let dport = u16::from_be_bytes([key[4], key[5]]);
                let proto = key[6];
                let nbytes = u64::from_le_bytes(val[0..8].try_into().unwrap());
                let npkts = u64::from_le_bytes(val[8..16].try_into().unwrap());
                out.push((key.clone(), daddr, dport, proto, nbytes, npkts));
            }
        }
    }
    out
}
```

- [ ] **Step 3:** In `main`, read the quota once and apply it in the loop. Replace the loop body's `for (daddr, dport, proto, nbytes, npkts) in parse_flows(&skel)` with:

```rust
    let quota = quota_bytes();
    println!("[ctl] egress quota = {} bytes/flow", if quota == u64::MAX { 0 } else { quota });

    loop {
        for (rawkey, daddr, dport, proto, nbytes, npkts) in parse_flows(&skel) {
            let attrs = [
                KeyValue::new("daddr", daddr.clone()),
                KeyValue::new("dport", dport as i64),
                KeyValue::new("proto", proto as i64),
            ];
            g_bytes.record(nbytes, &attrs);
            g_pkts.record(npkts, &attrs);
            // Fase 4.4e: enforcement decision — deny over-quota flows.
            if nbytes > quota {
                if skel.maps.deny.update(&rawkey, &[1u8], libbpf_rs::MapFlags::ANY).is_ok() {
                    println!("[ctl] DENY {daddr}:{dport} (bytes={nbytes} > quota={quota})");
                }
            }
        }
        let _ = provider.force_flush();
        tokio::time::sleep(Duration::from_secs(10)).await;
    }
```

(The `let quota = …` goes just before the existing `loop {`; remove the old `loop { for … }` and replace with the above.)

if echo "${resp}" | grep -aqE 'REQUEST_FAILED|error|""|provider|unreachable|timed out|503|502|500'; then
